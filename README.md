## Steps I followed
 1. I connected my ESP32-CAM to my laptop using a USB data cable.
2. I opened Arduino IDE and selected the AI Thinker ESP32-CAM board.
3. I selected the correct COM port to communicate with my ESP32-CAM.
4. I opened the CameraWebServer example and configured it to create a Wi-Fi Access Point.
5. I added a Wi-Fi network name and password.
6. I uploaded the code to my ESP32-CAM.
7. I opened Serial Monitor to check the IP address.
8. I connected my phone to the ESP32-CAM Wi-Fi network.

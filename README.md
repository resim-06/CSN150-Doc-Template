## Steps I followed
1. I connected my ESP32-CAM to my laptop using a USB cable.
2. I opened Arduino IDE and selected AI Thinker ESP32-CAM and COM3.
3. I opened the CameraWebServer example.
4. I entered my WiFi name and password in the code.
5. I verified the code and clicked Upload.
6. After fixing the connection error, the code uploaded successfully.
